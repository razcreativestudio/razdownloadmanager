Standar Keamanan (Security)

Bagaimana rilis RAZ Download Manager dikompilasi, diverifikasi keasliannya, dan cara melaporkan temuan kerentanan secara privat.

Menemukan Celah Keamanan?

Harap laporkan secara privat melalui fitur GitHub Security Advisories agar tim pengembang dapat merilis perbaikan (patch) sebelum detail teknis dipublikasikan.

Laporkan Kerentanan Privat

1. Bagaimana Rilis Dibuat

  • Otomatis via GitHub Actions: Setiap rilis installer dan paket biner dikompilasi langsung dari repositori open-source publik menggunakan runner server terisolasi milik GitHub. Seluruh log kompilasi bersifat publik dan dapat diaudit.
  • Daftar Checksum SHA-256: Setiap rilis resmi menyertakan berkas SHA256SUMS.txt. Lo dapat mencocokkan hash file yang lo donlot untuk memastikan file tersebut utuh dan tidak dimodifikasi oleh pihak ketiga.
  • Hanya Donlot dari Sumber Resmi: Pastikan lo hanya mendonlot RAZ Download Manager dari situs resmi kami (dm.it-raz.com) atau langsung dari GitHub Releases resmi.

2. Cara Verifikasi Hash SHA-256 di Windows

Lo bisa memeriksa hash SHA-256 file installer yang lo donlot menggunakan PowerShell dengan perintah berikut:

Get-FileHash -Algorithm SHA256 "RAZDownloadManager-1.0.1-setup.exe"

Bandingkan nilai hash yang muncul dengan teks hash resmi di halaman Pusat Donlotan.

3. Arsitektur Perlindungan Bawaan

  • Verifikasi Helper Eksternal: Modul pendukung seperti yt-dlp diverifikasi terhadap signing key resmi pembuatnya, dan FFmpeg dicocokkan dengan checksum resminya sebelum dieksekusi.
  • Tidak Ada Port Terbuka ke Internet: Server API otomasi secara default mati (disabled), dan jika diaktifkan hanya mendengarkan alamat loopback internal (127.0.0.1) dengan proteksi token rahasia lokal.
  • Sanitasi Nama File Unduhan: Nama file yang diterima dari server web selalu dibersihkan (sanitized) terlebih dahulu untuk mencegah serangan Path Traversal yang mencoba menulis file di luar folder tujuan lo.
  • Isolasi Kredensial & Cookies: Data login dan session cookies hanya dikirimkan kembali ke server domain asalnya, bahkan saat terjadi pengalihan (redirect) HTTP.
  • Memori Aman berbasis Rust: Engine inti dibangun dengan bahasa Rust yang menjamin keamanan memori (memory-safety) bebas dari ancaman klasik seperti buffer overflow, use-after-free, atau memory leaks.
