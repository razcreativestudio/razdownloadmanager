Pertanyaan yang Sering Diajukan (FAQ)

Temukan jawaban cepat seputar legalitas, lisensi gratis, cara integrasi, akselerasi kecepatan, dan keamanan sistem RAZ Download Manager.

Fondasi & Legalitas

Tentang RAZ Download Manager

Ya, 100% gratis selamanya tanpa tipu-tipu. RAZ Download Manager adalah perangkat lunak bebas & open-source di bawah lisensi resmi GNU General Public License v3.0 (GPL-3.0). Gak ada masa trial, gak ada lisensi berbayar, gak ada registrasi serial number, gak ada iklan, dan gak ada pop-up nag screen selamanya. Lo bebas pakai untuk kebutuhan pribadi maupun komersial di kantor/kampus.

Sama sekali bukan. RAZ Download Manager adalah software independen yang ditulis dari nol (clean-room implementation) menggunakan bahasa pemrograman modern Rust. Tidak ada satu baris kode maupun aset grafis milik Tonec Inc. (pembuat IDM) di dalam software ini. Tampilan dibuat familiar sengaja agar pengguna lama IDM bisa langsung nyaman tanpa perlu belajar ulang dari nol â€” dan karena 100% gratis, gak ada yang perlu di-crack! Jangan pernah donlot IDM bajakan/crack karena sering disusupi malware dan trojan berbahaya.

Selain antarmuka yang modern (Dark Glassmorphism), perbedaannya sangat signifikan:

  • Kecepatan Lebih Kencang: Di benchmark resmi kami, RAZ Download Manager menyelesaikan unduhan file 1 GiB dalam 1.01 detik (5.4Ã— lebih cepat dari IDM).
  • BitTorrent & Magnet Langsung: Mendonlot file torrent langsung dalam daftar yang sama tanpa software tambahan.
  • Multiplatform: Mendukung Windows 10/11, Linux (Debian, Ubuntu, Fedora, AppImage), dan macOS.
  • Dukungan AI MCP: Dilengkapi server Model Context Protocol untuk integrasi asisten AI modern.
  • 100% Gratis & Open Source: Lisensi GPL-3.0 bebas biaya selamanya.

Dijamin 100% aman dan bersih. RAZ Download Manager tidak mengandung adware, spyware, tawaran bundle bloatware, maupun tracking tersembunyi. Seluruh source code-nya terbuka untuk publik di GitHub. Setiap rilis installer dikompilasi secara otomatis oleh server GitHub Actions resmi dan disertai hash verifikasi SHA-256 untuk menjamin integritas file.

Nol data yang dikumpulkan (Zero Telemetry). Aplikasi ini tidak memiliki sistem akun, tidak memiliki analitik, dan tidak mengirim telemetri apa pun ke server kami. Aplikasi hanya terhubung ke server file yang sedang lo donlot dan ke GitHub untuk memeriksa update versi (yang bisa lo matikan di Opsi). Ekstensi browser hanya berkomunikasi secara lokal dengan aplikasi di komputer lo sendiri.

Sistem & Pemasangan

Instalasi & Kompatibilitas Sistem

Platform utama adalah Windows 10 dan 11 (64-bit). Kami juga menyediakan build resmi untuk Linux (AppImage, .deb untuk Ubuntu/Debian, .rpm untuk Fedora/RHEL, dan .tar.gz) serta macOS (.dmg untuk Apple Silicon & Intel). Seluruh paket rilis bisa lo akses di Pusat Donlotan.

Tidak didukung. RAZ Download Manager membutuhkan Windows 10 atau 11 64-bit. Toolchain compiler Rust modern serta sistem API I/O kecepatan tinggi (IOCP) yang kami pakai sudah tidak lagi mendukung sistem operasi lawas seperti Windows 7 dan 8.1 yang juga sudah dipensiunkan oleh Microsoft.

Bisa banget! Cukup donlot paket RAZDownloadManager-portable.zip di halaman donlot. Ekstrak ke folder mana pun, termasuk ke dalam flashdisk USB. Semua data antrean dan pengaturan tersimpan rapi di dalam subfolder data/ mandiri sehingga tidak menyentuh registry komputer host sama sekali.

Bisa dengan 1 klik! Di IDM lo, klik menu Tugas (Tasks) → Ekspor → Ke file ekspor IDM dan simpan file .ef2. Kemudian di RAZ Download Manager, klik Tugas → Impor → Dari file ekspor IDM dan pilih file .ef2 tersebut. Seluruh link, referer, cookies, dan deskripsi file akan langsung berpindah secara mulus!

Ekstensi & Browser

Integrasi Browser

Semua browser modern berbasis Chromium dan Firefox: Google Chrome, Microsoft Edge, Mozilla Firefox, Brave Browser, Opera, Vivaldi, Floorp, LibreWolf, dan Zen Browser. Ekstensi ini otomatis menyambungkan download link lengkap beserta session login sehingga file ber-login tetap bisa didownload dengan lancar.

Lo bisa donlot file ekstensi resmi .crx (untuk Chrome/Edge/Brave/Opera) atau .xpi (untuk Firefox) langsung dari halaman Donlotan Ekstensi kami. Di Chrome, buka chrome://extensions, hidupkan Developer Mode, lalu drag & drop file .crx ke halaman tersebut.

Periksa 3 poin ini: 1) Pastikan aplikasi desktop RAZ Download Manager sedang aktif di system tray; 2) Buka menu Opsi → Umum dan pastikan opsi "Gunakan integrasi browser tingkat lanjut" tercentang dengan browser lo dalam status dicentang; 3) Periksa di menu Opsi → Jenis File apakah ekstensi file tersebut sudah terdaftar.

Bisa banget! Cukup salin link file apa saja di browser, RAZ Download Manager yang mendeteksi clipboard otomatis akan langsung menawarkan pop-up download. Lo juga bisa menekan tombol Ctrl+V di aplikasi desktop atau drag & drop link ke jendela aplikasi.

Performa Engine

Kecepatan & Mesin Donlot

Browser biasa hanya mengunduh file melalui 1 koneksi tunggal (single thread). Jika server membatasi kecepatan per stream, donlotan lo bakal lambat. RAZ Download Manager memecah file menjadi hingga 64 segmen paralel secara dinamis. Bila ada salah satu segmen yang selesai lebih awal, engine Rust akan otomatis membelah sisa segmen yang masih besar (dynamic re-splitting) sehingga bandwidth internet lo termanfaatkan 100% tanpa henti.

Tentu saja. RAZ Download Manager menulis checkpoint progres secara aman ke penyimpanan lokal. Jika komputer mati lampu, koneksi WiFi putus, atau aplikasi ditutup, lo bisa langsung melanjutkan download persis di titik terakhir tanpa perlu mengulang dari 0%. Bahkan bila link kadaluarsa, lo cukup klik Perbarui Alamat Unduhan (Refresh Download Address).

Bisa! Manfaatkan fitur Penjadwal (Scheduler) di menu Unduhan. Lo bisa mengatur jam mulai (misal: 01:00 dini hari) dan jam berhenti, serta mencentang opsi auto-shutdown agar komputer lo otomatis mati begitu seluruh antrean selesai.

Ya, keduanya terintegrasi langsung. Untuk video, panel melayang "Donlot Video" akan muncul di browser didukung engine yt-dlp & FFmpeg. Untuk torrent, lo tinggal buka file .torrent atau klik link magnet:, pilih file mana saja yang ingin diunduh di pohon direktori, dan download akan berjalan di daftar yang sama.

Tidak bisa. RAZ Download Manager sengaja didesain untuk tidak merusak atau membobol proteksi hak cipta (DRM). Video yang diproteksi enkripsi DRM akan tetap terproteksi sesuai ketentuan hukum yang berlaku.

Teknologi Mutakhir

Otomasi, CLI & AI Assistant

Bisa! RAZ Download Manager dilengkapi server Model Context Protocol (razdownloadmanager-mcp). Lo bisa menyambungkannya ke aplikasi AI seperti Claude Desktop, Claude Code, Cursor, atau Antigravity untuk memerintahkan download melalui prompt bahasa alami santai.

Gunakan menu Bantuan → Laporkan Masalah di dalam aplikasi, atau langsung buka halaman GitHub Issues resmi kami. Tim developer kami menanggapi setiap laporan dengan cepat!
