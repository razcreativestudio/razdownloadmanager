Analisis Mendalam Tiga Skenario Utama

1 GiB Link Cepat

RAZ DM: 1.01 detik | IDM: 5.46 detik (5.4× lebih cepat)
RAZ DM membuka seluruh socket secara non-blocking seketika saat unduhan dimulai, memaksimalkan throughput jaringan sejak frame pertama tanpa ada delay inisialisasi.

KEUNGGULAN ENGINE RUST

File Kecil 256 KiB

RAZ DM: 0.03 detik | IDM: 3.14 detik (104× lebih cepat)
IDM membutuhkan waktu beberapa detik untuk membangun dialog UI, mengalokasikan file di disk, dan menulis metadata, sedangkan RAZ DM menyelesaikannya hampir seketika.

NOL LATENSI UI

Server Batas 2 Koneksi

RAZ DM: 12.6 detik (2 koneksi) | IDM: 15.9 detik (480 koneksi ditolak)
RAZ DM membaca respon server secara cerdas, membatasi diri pada 2 koneksi, dan mengingatnya. IDM mencoba membuka koneksi ratusan kali per detik yang menyebabkan throttling.

ADAPTIF & SOPAN

Metodologi & Lingkungan Pengujian

Pengujian dilakukan di mesin Windows 11 dengan prosesor AMD Ryzen / Intel Core modern, RAM 32 GB, dan NVMe SSD PCIe 4.0. Server uji lokal menjalankan simulasi transfer dengan kontrol bandwidth dan latensi presisi. Setiap skenario diulang sedikitnya 7 kali secara bergantian (alternating runs) untuk mengeliminasi bias caching OS, dan dihitung menggunakan nilai median dengan signifikansi statistik Mann-Whitney p < 0.001.
