Panduan Instalasi 3 Langkah Mudah

1. Jalankan Installer

Download file setup.exe di atas lalu klik dua kali untuk membuka. Jika muncul peringatan Windows SmartScreen, klik More info → Run anyway.

2. Pilih Opsi Integrasi

Pilih bahasa antarmuka lo dan pastikan centang opsi Set up browser integration agar browser lo langsung otomatis terhubung.

3. Mulai Unduh!

Buka RAZ Download Manager dari menu Start. Setiap link unduhan di browser atau link yang lo salin akan langsung ditangkap dengan kecepatan maksimal.

Integrasi Peramban

Ekstensi Browser (Unduh Langsung)

Unduh dan pasang ekstensi RAZ Download Manager secara langsung tanpa bergantung pada Chrome Web Store atau Add-ons Store. 100% aman, open-source, dan langsung terhubung dengan aplikasi desktop.

Chrome / Edge / Brave / Opera

Chromium Extension

File: razdm-extension-chrome.zip (~190 KB)
Mendukung Google Chrome, Microsoft Edge, Brave Browser, Opera, Vivaldi, dan seluruh browser berbasis Chromium.

Unduh Ekstensi Chrome (.zip)
Cara Pasang di Chrome/Edge:
  1. Ekstrak file razdm-extension-chrome.zip ke folder pilihan lo.
  2. Buka chrome://extensions (atau edge://extensions).
  3. Aktifkan toggle Developer mode (Mode Pengembang) di kanan atas.
  4. Klik tombol Load unpacked lalu pilih folder hasil ekstrak. Selesai!

Firefox Extension

File: razdm-extension-firefox.xpi (~192 KB)
Mendukung Mozilla Firefox, Firefox Developer Edition, Nightly, Zen Browser, Librewolf, dan Waterfox.

Unduh Ekstensi Firefox (.xpi)
Cara Pasang di Firefox:
  1. Unduh file razdm-extension-firefox.xpi di atas.
  2. Di Firefox, buka about:addons (atau tekan Ctrl + Shift + A).
  3. Klik ikon gerigi di kanan atas, pilih Install Add-on From File...
  4. Pilih file .xpi yang sudah diunduh lalu klik Add. Selesai!
