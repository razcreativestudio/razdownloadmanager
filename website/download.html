Panduan Instalasi 3 Langkah Mudah

1. Jalankan Installer

Download file setup.exe di atas lalu klik dua kali untuk membuka. Jika muncul peringatan Windows SmartScreen, klik More info → Run anyway.

2. Pilih Opsi Integrasi

Pilih bahasa antarmuka lo dan pastikan centang opsi Set up browser integration agar browser lo langsung otomatis terhubung.

3. Mulai Donlot!

Buka RAZ Download Manager dari menu Start. Setiap link donlotan di browser atau link yang lo salin akan langsung ditangkap dengan kecepatan maksimal.

Integrasi Browser

Ekstensi Browser (Donlot Langsung)

Donlot dan pasang ekstensi RAZ Download Manager secara langsung tanpa bergantung pada Chrome Web Store atau Add-ons Store. 100% aman, open-source, dan langsung terhubung dengan aplikasi desktop.

File .CRX Langsung

Chromium (.crx)

File: razdm-extension-chrome.crx (~198 KB)
Paket biner CRX resmi untuk Chrome, Edge, Brave, Opera, Vivaldi.

Cara Pasang (.crx):
  1. Donlot file .crx di bawah.
  2. Buka chrome://extensions (atau edge://extensions).
  3. Aktifkan toggle Developer mode di kanan atas.
  4. Tarik (*drag & drop*) file .crx ke halaman ekstensi, lalu klik Add extension.

Jika Chrome memblokir drag-and-drop offline, gunakan opsi (.zip) di sebelah.

Donlot File (.crx)
Metode Bebas Blokir

Chromium (.zip)

File: razdm-extension-chrome.zip (~190 KB)
Metode Load unpacked resmi & 100% aman tanpa batas kebijakan Google.

Cara Pasang (.zip):
  1. Ekstrak file razdm-extension-chrome.zip ke folder pilihan lo.
  2. Buka chrome://extensions (atau edge://extensions).
  3. Aktifkan toggle Developer mode di kanan atas.
  4. Klik tombol Load unpacked lalu pilih folder hasil ekstrak tadi. Selesai!

Direkomendasikan Google untuk ekstensi open-source pihak ketiga.

Donlot File (.zip)

Firefox (.xpi)

File: razdm-extension-firefox.xpi (~192 KB)
Mendukung Mozilla Firefox, Firefox Dev Edition, Zen, Librewolf, Waterfox.

Cara Pasang di Firefox:
  1. Donlot file razdm-extension-firefox.xpi di bawah.
  2. Di Firefox, buka about:addons (atau tekan Ctrl + Shift + A).
  3. Klik ikon gerigi di kanan atas, pilih Install Add-on From File...
  4. Pilih file .xpi yang sudah didonlot lalu klik Add. Selesai!

Format .xpi didukung langsung oleh browser keluarga Firefox.
