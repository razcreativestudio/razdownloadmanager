Pertanyaan Umum

Hal-Hal yang Sering Ditanyakan Seputar RAZ Download Manager

Penjelasan transparan dan santai biar lo makin paham cara kerja dan keunggulan RAZ Download Manager.

Apakah RAZ Download Manager beneran 100% gratis selamanya?

Iya, beneran 100% gratis! RAZ Download Manager dirilis dengan lisensi open-source GNU General Public License v3 (GPL-3.0). Gak ada sistem langganan bulanan, gak ada biaya lisensi tersembunyi, gak ada batas waktu trial 30 hari, dan gak akan pernah ada iklan sama sekali.

Kenapa kecepatannya bisa 5.4× lebih cepat dari IDM?

RAZ Download Manager ditulis murni menggunakan bahasa Rust yang terkenal sangat kencang dan aman dari memori leak. Engine kami membuka koneksi paralel secara simultan seketika sejak milidetik pertama dan langsung melakukan pembagian ulang potongan file (re-splitting) secara cerdas jika ada jalur koneksi yang lambat atau terhenti.

Apakah aman dari virus, malware, atau adware?

Sangat aman! Seluruh baris kode sumber terbuka untuk diaudit publik di GitHub. Build aplikasi dikompilasi secara otomatis melalui GitHub Actions CI/CD langsung dari kode sumber publik, bukan dari laptop pribadi. Setiap file rilis dilengkapi dengan hash SHA-256 resmi untuk verifikasi integritas file.

Apakah saya bisa download Torrent langsung tanpa software lain?

Bisa banget! RAZ Download Manager memiliki engine BitTorrent bawaan berbasis librqbit. Lo cukup klik tautan magnet link atau buka file .torrent, pilih file mana saja yang ingin didonlot, dan pantau potongan file (pieces) secara real-time langsung di jendela utama.

Bagaimana cara memasang ekstensi ke Google Chrome dan browser lain?

Saat lo menjalankan installer (setup.exe), pastikan opsi integrasi browser dicentang. Ekstensi untuk Chrome, Edge, Brave, Opera, dan Firefox bisa langsung didonlot secara direct dari halaman donlotan resmi kami (Pusat Ekstensi) tanpa perlu melewati Chrome Web Store atau Add-ons Store.

Bisa nggak saya impor riwayat atau daftar download lama saya dari IDM?

Bisa! Di IDM, pilih menu Tasks → Export → To IDM export file. Kemudian di RAZ Download Manager, cukup buka menu Tasks → Import → From IDM export file. Semua link dan status antrean lo akan langsung berpindah.
