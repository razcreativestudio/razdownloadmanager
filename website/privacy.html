Transparansi Data & Privasi

Kebijakan Privasi Resmi

Singkatnya: Aplikasi RAZ Download Manager dan ekstensi browser tidak mengumpulkan data apa pun tentang lo. Nol akun, nol analitik, nol telemetri, dan tanpa iklan.

Inti Kebijakan Privasi:

  • Aplikasi desktop dan ekstensi browser tidak mengirimkan data apa pun tentang lo kepada kami. Kami bahkan tidak menjalankan server penampung telemetri.
  • Aplikasi hanya menghubungi server file yang lo donlot dan GitHub untuk cek rilis terbaru (bisa dinonaktifkan di opsi).
  • BitTorrent berjalan peer-to-peer: komputer sesama swarm torrent melihat IP lo seperti cara kerja standar BitTorrent di seluruh dunia.
  • Ekstensi browser hanya berkomunikasi secara internal dengan engine RAZ Download Manager di komputer lo sendiri.
  • Seluruh riwayat donlotan, pengaturan, dan login tersimpan di komputer lo, tidak pernah diunggah ke cloud mana pun.

RAZ Download Manager adalah perangkat lunak bebas dan open-source (FOSS) di bawah lisensi GNU General Public License v3.0. Karena seluruh source code Open Source untuk umum di repositori GitHub kami, lo tidak perlu hanya percaya pada tulisan di halaman ini: setiap baris kode komunikasi jaringan dapat diaudit langsung oleh siapa pun di komunitas developer global.

1. Aplikasi Desktop

Apa Saja yang Tersimpan di Komputer Lo?

Daftar donlotan, preferensi setelan, akun yang lo simpan di Sites Logins, dan file yang lo unduh hanya tersimpan secara lokal di direktori aplikasi sistem lo:

  • Windows: %APPDATA%\razdownloadmanager (atau di folder data/ bila menggunakan versi Portable).
  • Linux & macOS: Di direktori konfigurasi standar pengguna (~/.config/razdownloadmanager).

Password akun download disimpan dengan enkripsi aman menggunakan sistem keychain bawaan OS lo (Windows Credential Manager, Linux Secret Service / Keyring, dan macOS Keychain).

2. Ke Mana Saja Aplikasi Terhubung di Jaringan?

  • Server Asal File: Untuk mendonlot file, RAZ Download Manager terhubung ke server penyedia file yang lo tuju. Server tersebut melihat IP address lo sebagaimana jika lo mendonlotnya melalui browser.
  • GitHub (Pemeriksaan Update Versi): Saat aplikasi dibuka dan sekali sehari saat berjalan, aplikasi mengirim permintaan GET sederhana ke public API GitHub (api.github.com) untuk mengecek apakah rilis baru sudah tersedia. Pemeriksaan ini bisa dimatikan sewaktu-waktu di menu Bantuan → Periksa Pembaruan.
  • GitHub (Helper Video & Audio): Jika lo mendonlot video streaming dari halaman web, aplikasi mengunduh modul pendukung resmi (yt-dlp dan FFmpeg) dari repositori resmi GitHub mereka dan memverifikasi tanda tangan kriptografisnya.
  • Swarm BitTorrent: Jika lo mengunduh file torrent atau magnet, aplikasi terhubung ke trackers dan peer lain di jaringan BitTorrent. Ini adalah protokol P2P standar.
  • Asisten AI (Hanya Jika Lo Hubungkan Sendiri): Server MCP bawaan (razdownloadmanager-mcp) hanya melayani program AI yang lo pasang di komputer lokal lo. Tidak ada data yang dikirim ke server AI eksternal kecuali apa yang diproses oleh aplikasi asisten AI yang lo gunakan sendiri.

3. Ekstensi Browser

Ekstensi browser RAZ Download Manager hanya bertindak sebagai jembatan penangkap link. Ekstensi ini tidak mencatat riwayat penjelajahan (browsing history), tidak menampilkan iklan injeksi, dan tidak mengumpulkan telemetri apa pun. Ekstensi hanya membaca URL download, cookie session unduhan, dan referer untuk diteruskan langsung ke aplikasi desktop melalui IPC (Native Messaging) lokal di komputer lo.

4. Pelaporan Kendala

Jika lo menggunakan menu Bantuan → Laporkan Masalah, aplikasi hanya menyiapkan link formulir GitHub Issues di browser dengan informasi nomor versi aplikasi dan sistem operasi lo. Tidak ada data yang dikirim secara otomatis sampai lo sendiri yang menekan tombol submit di GitHub.
