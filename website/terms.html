1. Lisensi Perangkat Lunak

RAZ Download Manager didistribusikan di bawah lisensi GNU General Public License, versi 3 (GPL-3.0). Lisensi ini menjamin kebebasan lo untuk menjalankan, mempelajari kode sumber, mengubah kode, dan mendistribusikan kembali perangkat lunak ini secara gratis.

Perangkat lunak ini sepenuhnya bebas biaya. Siapa pun yang mencoba menjual software ini kepada lo atau meminta uang registrasi untuk "membuka fitur" adalah pihak tidak resmi.

2. Penggunaan yang Bertanggung Jawab

RAZ Download Manager adalah alat bantu akselerasi unduhan, sama halnya seperti peramban web (browser). Lo menyetujui untuk menggunakan software ini secara bertanggung jawab dan mematuhi hukum yang berlaku:

  • Hanya mengunduh file atau konten yang lo memiliki hak izin atau hak cipta untuk mengunduhnya.
  • Tidak menggunakan software ini untuk merusak atau membobol sistem Digital Rights Management (DRM). RAZ Download Manager secara teknis tidak mendukung bypass DRM.
  • Saat mengunduh torrent, hormati hak pihak lain atas materi yang diunduh dan dibagikan secara peer-to-peer.
  • Tidak menggunakan software ini untuk menyerang, melakukan serangan DoS, atau melebihi kuota wajar server pihak lain tanpa izin.

3. Komponen Pihak Ketiga

Aplikasi dapat mengunduh alat bantu pihak ketiga resmi atas permintaan lo: yt-dlp (untuk menganalisis link video) dan FFmpeg (untuk menggabungkan audio dan video). Masing-masing dikelola di bawah lisensinya sendiri (yt-dlp: Unlicense; FFmpeg: LGPL/GPL).

4. Batasan Garansi & Tanggung Jawab

Sesuai pasal 15 dan 16 lisensi GNU GPL, perangkat lunak ini disediakan "SEBAGAIMANA ADANYA" (AS-IS) TANPA JAMINAN APA PUN, baik tersurat maupun tersirat. Kami tidak bertanggung jawab atas segala bentuk kerugian, kehilangan data, atau kerusakan perangkat keras yang mungkin timbul dari penggunaan software ini.

5. Merek Dagang & Nama

"RAZ Download Manager", logo RAZ, dan identitas visual ekosistem RAZ adalah identitas dari proyek ini.

Nama "Internet Download Manager" dan "IDM" adalah merek dagang terdaftar milik pemiliknya masing-masing (Tonec Inc.). Penyebutan nama-nama tersebut di situs ini murni bertujuan untuk tujuan deskriptif dan komparasi teknis yang diperbolehkan hukum. RAZ Download Manager sama sekali tidak berafiliasi, tidak disponsori, dan tidak menggunakan aset milik Tonec Inc.

RAZ Download Manager adalah proyek download manager modern open-source berkecepatan tinggi dari ekosistem RAZ Creative Studio.
